## Variant: Guided split

### Design stance
Help visitors start from the job their agent needs to do, not from an unfamiliar taxonomy.

### Key choices
- Layout: split hero with search on the left and task-based shortcuts on the right; compact full-width result rows.
- Typography: keeps the existing mono identity while using body type for explanations.
- Color: reuses the current near-black, grey, and teal system.
- Interaction: live search and task/capability filters.

### Trade-offs
- Strong at: onboarding people who do not yet understand the category names; explains the evidence bar without a long page introduction.
- Weak at: the task labels require careful mapping as the taxonomy grows and can oversimplify categories.

### Best for
- First-time visitors arriving from broad searches such as “tools for AI agents”.
