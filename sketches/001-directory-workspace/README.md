## Variant: Directory workspace

### Design stance
Treat the homepage as a practical directory interface, with compact context and persistent filters.

### Key choices
- Layout: compact headline, sticky category sidebar, search-led two-column result workspace.
- Typography: keeps the existing mono identity and reduces oversized display text.
- Color: reuses the current near-black, grey, and teal system.
- Interaction: live search, persistent category filtering, and a mobile filter drawer.

### Trade-offs
- Strong at: browsing many records, desktop density, direct access to filters, growth beyond the current 38 tools.
- Weak at: more product-like and less editorial; the sidebar consumes space and collapses on smaller screens.

### Best for
- Repeat visitors and power users comparing many tools across categories.
